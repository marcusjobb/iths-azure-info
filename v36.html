Docker i produktion

ITHS · Administrera molnlösningar · Marcus Ackre Medina

"It works on my machine." — Varje utvecklare, precis innan Docker löste det

Veckans ämnen

⚡
Layer-caching
Lagerordning avgör byggtid. Rätt COPY-ordning sparar minuter per build.
📦
Multi-stage build
Separera build-miljö från runtime. SDK i produktion är ett anti-pattern.
🙈
.dockerignore
Exkludera bin/, obj/, .env. Glöms alltid — nu vet ni om det.
💓
HEALTHCHECK
Kubernetes behöver veta om er container faktiskt svarar — inte bara startat.
🔐
Secrets
ENV i Dockerfile = credentials i klartext. Key Vault + Managed Identity.
📋
ACR + AcrPull
Azure Container Registry med Managed Identity — inga admin-credentials.

Utmaning — HEALTHCHECK i Dockerfile. Verifiera att ACI rapporterar healthy.
